# 三维植株与交互升级

本轮保留原有页面布局、颜色、角色和 Agent 编排，不增加依赖、不使用外部模型。形态参数依据本轮需求制作，不代表特定品种的严格农艺标准。

## 植株组织

```text
MainPlant
├── 吊蔓钢丝、垂直绳
└── P01 动作根 Group
    ├── 底粗顶细的主茎、固定夹
    ├── CompoundLeaf × 12（P01_LEAF_01...12）
    │   ├── Petiole：真实曲线叶柄
    │   └── Rachis：近端轴与可偏转的远端轴
    │       ├── PrimaryLeaflets：3–5 对
    │       │   └── 独立小叶关节 → Petiolule → Blade + 主侧脉
    │       ├── IntercalaryLeaflets：2 片
    │       └── TerminalLeaflet：1 片
    │           └── P01_LEAF_07 顶生小叶附着模拟病斑
    ├── FruitTruss × 2
    │   ├── Peduncle：果串总梗
    │   ├── Rachis：弯曲果串轴
    │   └── Pedicel × 3
    │       ├── 保留在串上的果梗
    │       └── 原 Tomato Group（采摘与入箱始终为同一对象）
    └── 花序柄与花朵
```

主植株共有 128 个小叶/顶生叶/间生叶 Blade，约为原主植株 65 个 Leaf 的两倍。背景六株使用每株四片简化复叶，降低背景细节开销。形态变化为确定性参数，刷新不会随机改变叶片 ID 或组织。

## 叶片与病斑

每片复叶有根部旋转中心，叶轴远端有次级转动中心，每个小叶有自己的关节和小叶柄。不同高度、方向、大小、形状与材质色调形成冠层。三种叶面几何和主侧脉为共享资源；相同数值的管道几何缓存复用，不随 React 传入新数组重复创建。没有每帧创建 Geometry。

LEAF_01 是保留的专家任务入口，映射到 `P01_LEAF_07_TERMINAL`；遮挡对象是另一片复叶 `P01_LEAF_06`。斑枯病外观模拟使用不规则黄晕、褐色边缘、浅灰褐中心和少量黑点。所有病斑顶点由与叶面相同的参数曲面计算，加微小法线偏移避免深度闪烁，并随承载小叶全部变换。它不代表检测或诊断结果。

## 统一动作与同步

保留 `action` 原有字段，额外提供 `leaf_id`、`truss_id`、`affected_leaf_ids`。旧的 `LEAF_01`、`harvest/reveal`、确认卡、动作 UUID、NDJSON、最终 ack 与现有 HTTP 路径不变。

`SceneMotionProvider` 只使用一个 `action.startedAt` 计算进度，依次更新主茎、果串、复叶、果梗、小叶、果实、机器人。对象注册表通过稳定 ID 关联目标；没有按对象创建计时器。机器人通过注册目标的实际世界坐标接近或跟随触点。

- **拨叶**：接近实际叶轴触点 → 叶柄根部偏转 → 远端叶轴轻弯 → 小叶延迟摆动、邻叶/主茎微动 → 退出与轻微衰减回弹。成功后用 `world.revealed` 保留观察位置。T06 与区域遮挡字段同步清除，但 `harvestable=false`、成熟度和分数保持原值。
- **采摘**：果梗轻弯、邻叶避让 → 夹爪闭合 → 在分离瞬间记录原果实世界位置 → 同一 Group 提起、转运、放置 → 果梗保留，果串/叶片小幅回弹。原 Group 保持在果串层级中，通过父节点 `worldToLocal` 补偿运动，不重新挂载、不缩放切换、不创建箱内副本。
- **提交与恢复**：计时结束仅发一次 ack，前端保持放置姿态直到后端 `state` 确认提交；后端拒绝、false ack、超时或断流时以服务端快照恢复。任务执行中禁止重置；成功重置后原对象恢复挂载位置、复叶初始姿态，清空对话与观察状态。

## 验证

```bash
export PATH="$PWD/.tools/bin:$PATH" # 使用项目内 Node 时
npm run build
.venv/bin/python -m pytest -q tests/test_agent.py
npm run test:e2e
```

既有 E2E 继续覆盖农户三果采摘、学生错误/正确选果、专家拨叶、报告/趋势弹窗和窄屏布局。新增 E2E 使用开发态只读检查器进行真实 Mesh 射线检测，并验证原果实 UUID、箱内世界坐标与失败回滚；检查器不进入生产构建。

本轮实际结果：`npm run build` 成功；后端 **10 passed**（另有第三方 TestClient 弃用提示）；E2E **3 passed**。原三角色完整流程、桌面/窄屏布局、三个预设视角的真实挡叶射线、拨叶后完整场景中的病斑观察点可见、同一果实 UUID 入箱与重置、false ack 回滚均通过。

## 当前仍未实现

- 没有真实物理、碰撞求解、力反馈或逆运动学；接触、弯曲、延迟与回弹是同步预设运动。自动避碰不在本轮范围内。
- 小叶表面为有起伏的双面曲面；动画弯曲主要通过叶柄/分段叶轴/小叶关节完成，没有软体或逐顶点力学。
- 遮挡标志以配置观察任务与成功动作提交为依据，不是用户任意旋转相机后实时更新的遮挡率。射线检查用于本轮视角验收，不替代作物识别。
- 仍无会话持久化、跨用户协作；刷新会按服务器快照恢复收获/拨叶结果，后端重启会清空演示。
- 未对真实 GPU 设备做 FPS/显存基准；自动浏览器使用软件 WebGL，不能据此声称实际硬件渲染性能。
- 未配置真实模型 API 密钥，模型服务商联网验证范围与上一版相同；三种本地演示流程继续执行真实 Skill 函数。
